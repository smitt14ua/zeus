# Glossary

## Domain Terms

**basic.cfg**
Network performance configuration file for Arma 3 servers. Configures packet sizing,
bandwidth limits, and update thresholds. Generated by ZEUS from the `basic:` profile
section. Passed to the server via `-cfg`. See [basic.cfg Reference](formats/basic_cfg.md).

**BattlEye (BE)**
Anti-cheat system integrated into Arma 3. Enabled via `BattlEye = 1` in server.cfg.

**bikey / .bikey**
Bohemia Interactive digital signing public key distributed with signed mods. Placed in
the server's keys directory. The server checks connecting clients' mod signatures
(`.bisign` files) against loaded `.bikey` keys to verify addon authenticity.
File extension must be lowercase `.bikey` for ZEUS to recognize them.

**bisign / .bisign**
Bohemia Interactive digital signature file. Each addon PBO has a companion `.bisign`
file signed with the mod author's private key. Clients send these to the server, which
validates them against the corresponding `.bikey`.

**HC / Headless Client**
A client instance connected to the server without a rendering window. Used to offload
AI processing. Whitelisted via `headlessClients[]` in server.cfg. The IPs in
`localClient[]` are treated as having near-zero latency.

**install_dir**
The Arma 3 dedicated server installation path. Root for relative paths passed to the
server process. ZEUS places all profile data under `<install_dir>/.zeus/<profile_name>/`.

**mod**
An Arma 3 modification consisting of PBO files in an `addons/` subdirectory. Named
with `@` prefix by convention (e.g. `@CBA_A3`). May include sub-mods (`@` directories
inside the mod folder) and keys.

**MOTD (Message of the Day)**
Lines of text displayed to players on connect. Configured via `motd[]` and `motdInterval`
in server.cfg.

**MPMissions**
Directory containing multiplayer mission files (`.pbo` or unpacked folders). Default
location is `<install_dir>/MPMissions/`. ZEUS manages a per-profile override at
`<install_dir>/.zeus/<name>/mpmissions/`.

**PBO**
Packed BI Object — the Arma 3 archive format for addons and missions. Analogous to a
zip file.

**PID file**
A text file containing a process ID. Created by Arma 3 at startup (via `-pid`), deleted
on clean exit. ZEUS uses PID files at `~/.zeus/running/<name>.pid` to track running
server instances.

**Profile**
A named, persistent server configuration managed by ZEUS. Stored as a YAML file at
`~/.zeus/profiles/<name>.yaml`. Contains startup parameters, server config, and basic
config in a single document.

**RPT file**
Arma 3 report log. Contains server console output, script errors, and diagnostics.
Location set by `logFile` in server.cfg or defaults to crash dump directory.

**server.cfg**
Primary Arma 3 server configuration file. Controls authentication, player limits,
voting, and lifecycle. Generated by ZEUS from the `config:` profile section.
See [server.cfg Reference](formats/server_cfg.md).

**simulation cycle**
Arma 3's equivalent of a rendering frame on the server (no rendering occurs).
Each cycle: AI simulation → physics → visibility → scripts → network receive → network
send. `MaxMsgSend` limits packets per cycle.

**submod**
A mod directory (prefixed with `@`) nested inside a parent mod directory. When ZEUS
processes a mod, it offers to include detected submods.

**VoN (Voice over Net)**
Arma 3's integrated voice chat. Controlled via `disableVoN`, `vonCodec`, and
`vonCodecQuality` in server.cfg.

## ZEUS-Specific Terms

**Profile YAML**
The user-facing configuration format. Snake_case keys. Loaded by `ProfileLoader`,
stored by `ProfileRepository`, rendered to Arma configs by `ProfileWriter`.

**force mode**
Activated by `--force` flag or automatically when stdin is a pipe. Skips all interactive
prompts, using defaults: submods not included, keys copied, unknown keys kept.

**managed parameters**
Startup parameters set automatically by ZEUS (`-config`, `-cfg`, `-pid`, `-profiles`,
`-name`, `-keysFolder`, `-mpmissions`). Must not be overridden in profile YAML.
